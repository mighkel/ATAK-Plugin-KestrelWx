# ATAK-Kestrel Public

Public release and issue-tracking repo for the ATAK-Kestrel plugin.

This repo is intentionally limited to public-safe materials:

- release notes
- tester guidance
- known issues
- issue templates
- signed release assets distributed through GitHub Releases

## Install

1. Download the latest signed APK from GitHub Releases.
2. Transfer it to an ATAK-compatible Android device.
3. Install the plugin.
4. Open ATAK and confirm the plugin is discovered.

## Reporting Issues

Please include:

- ATAK version
- Android device model
- Android OS version
- plugin version
- what you expected
- what actually happened
- screenshots if helpful

## Notes

This public repo is not the full development repo. Private source and internal development notes remain in a separate repository.
